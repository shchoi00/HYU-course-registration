# 취케팅 조회 간격 랜덤화 설계

## 목표

취케팅의 희망수업 조회 간격을 고정 0.5초에서 평균 1초의 작은 랜덤 간격으로 변경한다. 각 조회 라운드가 끝날 때마다 `0.7~1.3초` 사이의 값을 균등하게 새로 선택한다.

## 범위

- 운영 진입점에서 사용하는 취케팅 대기 함수만 변경한다.
- 한 번의 조회로 선택 과목 전체를 확인하는 기존 방식은 유지한다.
- 예약 시각, 로그인, 세션, 토큰, 정원 판정, NetFunnel 및 수강신청 요청 로직은 변경하지 않는다.
- README의 취케팅 주기 설명을 실제 동작과 일치시킨다.

## 구현

`main.py`에 테스트 가능한 작은 대기 함수를 추가한다. 이 함수는 주입 가능한 균등 난수 함수로 `0.7~1.3` 값을 얻고, 주입 가능한 sleep 함수에 전달한다. `main()`은 기존 고정 0.5초 lambda 대신 이 함수를 `run_application()`에 전달한다.

## 검증

- 난수 범위가 정확히 `0.7~1.3초`로 요청되는지 단위 테스트한다.
- 선택된 대기 시간이 그대로 sleep에 전달되는지 단위 테스트한다.
- 운영 wiring이 새 대기 함수를 전달하는지 확인한다.
- 전체 기존 테스트와 정적 검사를 다시 실행한다.
